# Webの例題条件と一般的な性質の区別

2026-09-28。円の解説10で「長さは2倍」が定理のように読めた、という利用者の指摘を受けた点検。

## 原因と対応

条件の説明が図の下にあり、数値の由来より先に「2倍」という見出しが現れていた。途中の「長さを求める」から開くと、紙の問題を見ていない人には特に分かりづらかった。

- 図より前に、例題の設定・与えられた長さ・求めるものを常時表示する。
- 「相似なら対応する辺の比がそろう」と「この例では6÷3で2倍」を分ける。
- 拡大した図でも条件が読めるよう、元図に条件を添え、比較図の「2倍」は「6÷3＝2倍」とする。
- 接線の例でも、与えられた角と求める角を先に示す。Bを動かすと条件欄の角度も連動する。
- 制作ガイドラインに、条件・説明用の設定・計算結果・一般的な性質を区別し、途中から読む場合も点検するルールを追加する。

## 確認する操作

- 円の解説10を初めて開く／「長さを求める」へ直接進む／前へ戻る。どの場合も条件が図より先にある。
- 元図を拡大し、例題の3・6・4が読み取れる。比較図の倍率は6÷3から得られる表示になっている。
- 接線でBを動かし、条件欄・図・計算の角度が一致する。
- 相似の対応体験と三平方の特別な比で、具体的な倍率・長さを性質と取り違えない。
- 既存の図の衝突・等縮尺・全段階・操作検査と、公開前の全体テストを利用する。
