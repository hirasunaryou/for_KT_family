## 確定した不整合・操作不具合

### N01 / P2：勉強の入口が、現在の教材数・内容を伝えていない

- 場所: `study/index.html:1` の「教科から探す」内、数学カードとプログラミングカード。
- 公開・作業版の両方で、数学が **「2つの教材 · 中3」「平方根と二次関数」** のまま。公開ホームには既に数学4単元、作業版には6単元ある。
- プログラミングは「2つの学び方」「サイコロ探偵」「JupyterLab版とブラウザ版」とだけ説明。実際のプログラミング一覧には金庫破り・迷路・ドット絵もあり、サイコロの2モードだけと誤解させる。数学の単元カード（二次方程式）と教科カード（数学）が同列に並び、階層も混在している。
- 学習者への影響: ホームの「教材を探す」「すべての教材」から進んだ先で、増えた教材が減ったように見える。相似や画像制作を探す家族が、その教科に入ってよいか迷う。
- 提案: 教科カードの粒度を統一し、単元一覧と同じ情報源から件数・短い内容を作る。件数を表示するなら公開状態に応じて数える。

### N02 / P2：「本文へスキップ」が、勉強中の章から遊ぶ画面へ戻してしまう

- 場所: `study/programming/python-dice-vault/index.html:1`、`python-maze-robot/index.html:1`、`python-pixel-monster/index.html:1` の `href="#main"`。
- 根本: `assets/python-dice-vault/app.js:20`、`assets/python-maze-robot/app.js:25`、`assets/python-pixel-monster/app.js:24`。`#mission-*` と `#setup` 以外のハッシュをすべて遊ぶ画面として扱い、`hashchange` で再描画する。
- 再現: `#mission-2` を開く → キーボードで「本文へスキップ」をフォーカス → Enter。
  - 金庫: 「持ち帰る？ まだ欲張る？」→「サイコロ金庫破り」
  - 迷路: 「壁をすり抜けないプレイヤー」→「迷路メーカー＆脱出ロボット」
  - ドット絵: 「色違いと、おばけを作る」→「ドット絵モンスター工房」
- 学習者への影響: ナビゲーションを飛ばして読みたい操作で、本文そのものが別の内容に変わる。キーボード利用時に特に影響。
- 提案: ページ内アンカーと画面切替のルーティングを区別し、`#main` では現在のミッションを保ったまま本文にフォーカスする。

### N03 / P2：Jupyter版だけ、ブラウザの「戻る」で前のミッションに戻れない

- 場所: `assets/python-dice-jupyter/app.js:29`、`go()` の `history.replaceState()`。
- 再現: プログラミング一覧 → Jupyter版 `#mission-1` →「次のミッションへ」→ ブラウザ「戻る」。MISSION 1ではなくプログラミング一覧へ戻る。履歴件数は次へ操作前後で同じ。
- 他の制作教材は `location.hash=...` で履歴を積むので、同じサイトでも戻る操作の意味が違う。
- 学習者への影響: 前の説明を読み返そうとして教材から離脱する。保存されていないコード入力があるという意味ではなく、読書の位置が戻れない問題。
- 提案: ミッション移動を通常の履歴として残し、ハッシュ変更・戻る・進むの双方から内容を復元する。

### N04 / P2（利用条件限定）：JSが動かない場合、Python教材の読む部分・教材ファイルへの道が消える

- 場所: `study/programming/python-dice/index.html:1`、`dice-lab.html:1`、`python-dice-jupyter/index.html:1`、`python-dice-vault/index.html:1`、`python-maze-robot/index.html:1`、`python-pixel-monster/index.html:1`。
- 実測: ブラウザ版2ルートは本文が空・リンク0。Jupyter版はヘッダーだけ。後続3教材は「JavaScriptが必要」の案内とヘッダーのみで、Notebook・道具ファイルのダウンロードも表示されない。
- 学習者への影響: 設定でJS無効、スクリプト読込失敗などのとき、ゲームだけでなく「読む」「ファイルを受け取ってJupyterで作る」まで止まる。通常のJS有効時は46状態とも初期化エラーなし。
- 提案: 最小限の説明・準備・教材ファイル導線をHTMLに置く。ブラウザPythonには最低限、必要な機能の説明とJupyter版／教材一覧への避難導線を出す。

## 実物で確認した設計上の改善点（現行挙動のバグとは区別）

### N05 / P2：学ぶ順序が一覧から分からず、既習→次の単元へ進む矢印もない

- 場所: `study/math/index.html:1`、各単元の先頭・末尾。相似の生成元は `scripts/build-similarity.py:135,140`、円 `scripts/build-circle.py:85`、三平方 `scripts/build-pythagorean.py:84`。
- 確認した状態: 作業版の数学一覧は **三平方→円→相似→二次方程式→二次関数→平方根** の追加順。初めての人向けの「ここから」「必要な前の学び」、または既習者向けの「必要な単元へ」という並びの説明はない。
- 平方根・二次関数から次の数学単元へ直接進むリンクはない。相似は以前の3単元へのリンクだけ。円の最終章は「円から直角へ。その先は三平方」と説明しているが、作業版でも三平方へ進むリンクはない。
- 学習者への影響: 「前の学びが次の道具になる」という中身は充実しているのに、サイト上の移動は毎回数学一覧に戻って自分で選ぶ必要がある。追加順を学習順と誤解しやすい。
- 提案: 学校の順番を強制せず「最初から学ぶ目安」と「復習したい単元を選ぶ」を短く区別。末尾に次の単元の使いどころを一言添えたリンクを設ける。円→三平方のリンクは三平方公開時に追加し、公開前からリンク切れを作らない。

### N06 / P2：「前の単元へ」が、必要な説明ではなく毎回教材の先頭へ飛ぶ

- 場所: 相似・円・三平方の導入にある既習単元へのリンク。`scripts/build-similarity.py:135`、`scripts/build-circle.py:85`、`scripts/build-pythagorean.py:84`。
- 確認した状態: 例えば三平方「面積から長さへ」「相似からも…」「長さが分からなければ、x…」に関連する既習リンクは導入部の単元名だけで、それぞれ該当する説明へは直行できない。円の相似活用章も同様。
- 良い例: 相似の体験4は `../quadratic-functions/index.html#apply` の「二次関数の三角形で比較する」があり、具体的な内容まで届く。この精度が他の接続にはまだない。
- 学習者への影響: 忘れたことを確認するたびに、長い別教材の目次から再探索する。「探し回らなくてよい」という図の方針がページ間では途切れる。
- 提案: その場に「√で長さに戻す説明」「平方根を使う解き方」など内容が分かる短いリンクを置き、対象の既存アンカーへ直行できるようにする。復習から元の問題へ戻る方法も合わせて考える。

### N07 / P3：ホームの主ボタンが、教材の増加と無関係に二次関数へ固定されている

- 場所: `index.html:1` の `.hero .actions`。公開ホームでも確認済み。
- 状態: サイトは数学4単元（作業版6）、Python複数テーマに拡大したが、最も強い主ボタンは常に「二次関数を開く」。下のカードは新しい単元から並ぶ。なぜこの1教材が選ばれているか説明はない。
- 評価: リンクは正常であり、二次関数を特集する意図なら誤りではない。ただ、今学ぶべき順番・前回の続きと誤解される余地がある。
- 提案: 家族全員の入口として「教材を選ぶ」を主にするか、「今月のおすすめ」など選定理由を明示する。前回の続きは記録機能との連携まで含む別検討にする。

### N08 / P2：円のWeb体験は「紙へ戻って確かめる」出口が弱い

- 場所: `materials/circle/labs.html` の3体験。生成先 `study/math/circle/index.html:1`。
- 状態: 入口には「問5〜8のあと」等のタイミングがある一方、体験終了後は「気づきを整理する」という説明で終わり、別問題へのリンク・短い再挑戦の問いがない（3 lab内のリンク数0）。
- 比較: 相似は各体験末尾に問2・5・17・28への具体的なリンク。三平方は各体験末尾に「紙へ：…」という条件を変えた問いがあり、方針に沿っている。
- 学習者への影響: 動かして分かった気持ちから、自分の式や理由で解くところへ戻る手掛かりが弱い。円単元の3体験で実際に差が見られる。
- 提案: 体験後に1問だけ、別条件で理由を書かせる紙の問題を示す。既存問題番号を動かさず、対応先リンクを付ける。

### N09 / P3：平方根だけ、教材名・サイト名・主要操作の語彙が以前のまま

- 場所: `study/math/square-roots/index.html:7,15,18–23`。
- 状態: ブラウザタイトルは「平方根の学習室 | Family Learning」、ブランドは「Family Learning / 家族の学習室」。他ページは「家族のまなび帳」。サイドには別途「← 家族のまなび帳」があるので移動は可能。
- 学習者への影響: 同じ家族教材にいることが少し分かりづらい。初期教材の入口だけ別サービスの印象になる。
- 提案: 数学的な中身や気に入られている操作は維持し、サイト名・戻り先・PDF呼称等の最小限を統一する。
