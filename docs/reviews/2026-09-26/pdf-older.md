## 確認できた改善対象

### OLD-PDF-01 / P2：二次関数の三角形面積で、解答に肝心の分割図がない

- 場所：`print/quadratic-functions-answers.pdf` p5 問26、p7 問38。関連：`print/quadratic-functions-guide.pdf` p5。
- 確認事実：問26は「y軸で分けると底辺2、高さ2と1」「OCを共通の底辺」、問38は「共通の底辺は6a。高さは2と3」と文章・式で説明するが、そのページに三角形の図がない。解説p5には図があるものの、OAC・OCBの2領域の区別や、底辺OC・横向きの高さ1と2への直接注記がない。
- 影響：学習の核心である「縦のOCを底辺にしたから高さは横」を、読者が座標や文字から頭の中で再構築する必要がある。最新の三平方教材で問題にしている「図のどこ？」に相当する。
- 改善案：解答側だけに、分けた2三角形、共通底辺、横の高さ、面積式の各因子を同じ印で対応させた小さな図を入れる。問題集の自力作図余地は残す。
- 根拠：`quadratic-functions-answers-5.png`、`quadratic-functions-answers-7.png`、`quadratic-functions-guide-5.png`。
- 原稿参照：`materials/quadratic/questions.json` 問26（228行付近）、問38（336行付近）。ただし現PDFを再生成するコードは後述の通り未収録。

### OLD-PDF-02 / P2：変化の割合の式が、図のどの長さを割るのか直結していない

- 場所：`print/quadratic-functions-guide.pdf` p3。関連：解答p4 問17～24。
- 確認事実：A・Bと直線ABのグラフ、右側の `(9-1)/(3-1)=8/2=4` はあるが、グラフには横2・縦8の階段、増加量の寸法線、分子・分母と対応する印がない。A(1,1)・B(3,9)の座標も図中に一組で書かれていない。
- 影響：子供は小さな目盛りを読んで、文章・式・グラフを往復する必要がある。『2点を結ぶ直線の傾き』という意味の理解が、式の代入に寄りやすい。
- 改善案：横の増加2、縦の増加8を図中の直角の階段で示し、式の2・8と線種・印で対応させる。変域ページp4も、xの範囲とyの範囲を軸の外側の短い帯で示せる。
- 根拠：`quadratic-functions-guide-3.png`、`quadratic-functions-guide-4.png`、`quadratic-functions-answers-4.png`。

### OLD-PDF-03 / P2：二次関数のグラフ目盛りが7pt、説明の本文よりかなり小さい

- 場所：`print/quadratic-functions-guide.pdf` p2～5、問題集p3、解答p3。
- 確認事実：PDF文字情報で目盛り数字・原点Oは **7pt**。ガイド本文は主に10～11pt。p2の3本比較図と、p3の変化の割合図では図そのものも細く、数値を読む作業が集中している。
- 影響：画面拡大では読めるが、A4印刷で小さい数字に目を凝らす負担がある。特にグラフから数値を読み取らせる箇所で不利。
- 改善案：等縮尺は維持し、読み取りに必要な目盛りを9pt前後にする。図の幅・配置を見直すか、不要な目盛り数字を間引いて、A・Bの座標は近くに直接表示する。単に図を非等方拡大しない。
- 根拠：`quadratic-functions-guide-2.png`、`quadratic-functions-guide-3.png`、`quadratic-functions-workbook-3.png`。フォントサイズは pdfplumber の char.size で実測。

### OLD-PDF-04 / P2：紙から対応するWeb体験へ戻る手がかりがない

- 場所：今回点検した6冊全体。
- 確認事実：6冊ともPDFリンク注釈は0。印刷面に教材WebのURL・QR・Web体験番号がなく、紙の各章に対応する動く図の案内がない。各冊どうしのページ参照はある。
- 影響：紙だけを机に持ってきた学習者が「今の式を動かしてみる」場所を自分で探す必要があり、保護者の誘導に依存しやすい。紙→Web→別の紙問題という流れが教材単体で完結しない。
- 改善案：表紙または最終ページに単元Webの短いURLとQR、図のある章の末尾に『Webでこの量を変える／ここを予想する』という一行＋対応先を付ける。PC主体なら読めるURLも併記しQRだけにしない。
- 根拠：全40ページPNG、抽出テキスト、全PDF `/Annots` が0。

### OLD-PDF-05 / P2：平方根の発展で『ペアにする』『面積から辺』をもう一段図示できる

- 場所：`print/square-roots-guide.pdf` p5、`print/square-roots-answers.pdf` p4 問26・27。
- 確認事実：p5は「素因数を2個ずつのペアにすると、2だけが1個余っています」と文章で説明し、`18=3²×2` を示すが、ペアや余った2の視覚的なまとまりがない。面積12の正方形から一辺・周を求める例にも正方形の図がない。解答問26・27も文字と式だけ。
- 影響：平方根p1で作れている「面積↔辺」の理解や、余る素因数の意味を、発展問題で見失いやすい。これは誤りではなく、後の相似・三平方への橋をさらに強くできる具体的な箇所。
- 改善案：`3×3×2` で3のペアを囲み、もう一つの2を追加する小図を置く。面積問題は正方形の内側に12、外側の辺に√12を表示し、周の4本と式を対応させる。
- 根拠：`square-roots-guide-5.png`、`square-roots-answers-4.png`。

### OLD-PDF-06 / P3：『ヒントだけ見る』という案内と、答えが先に目に入る配置

- 場所：`print/square-roots-answers.pdf` p1（全解答の共通書式）、`print/quadratic-functions-answers.pdf` p1（共通書式）。
- 確認事実：「最初はヒントの行だけ見る使い方でもOK」「まずヒントだけ見てもOK」と案内される一方、各問題の大きな正答→途中式→本文→小さなヒントの順に同じ領域へ掲載されている。
- 影響：紙でヒントだけ探すと、正答が先に視界に入りやすい。意図した段階的援助と紙の見せ方が一致していない。
- 改善案：ヒントだけの小ページを別に置く、問題集末尾へ短いヒントを分ける、または「ヒントだけ」の案内を実際の運用に合わせる。正答の文字を小さくする方向で解決しない。
- 根拠：`square-roots-answers-1.png`、`quadratic-functions-answers-1.png`。

### OLD-PDF-07 / P3：比較する3本の放物線と式の対応が離れている

- 場所：`print/quadratic-functions-guide.pdf` p2。
- 確認事実：3つの式を図の上で横一列に表示。線種（破線・実線・点線）とaの対応はグラフより下の凡例を読む必要がある。曲線の近くに式・aの直接ラベルはない。
- 影響：3つの式の横順がそのまま曲線の位置を示すわけではないため、どの曲線のことか確認する視線の往復が生じる。
- 改善案：白黒の線種を残したまま、余白へ短い引き出し線で式を直接つける。式・凡例・曲線の対応を一か所で見せる。
- 根拠：`quadratic-functions-guide-2.png`。

### OLD-PDF-08 / P3（保守上）：旧6冊はPDFの生成元・再生成手順がリポジトリ内にない

- 場所：`print/square-roots-*.pdf`、`print/quadratic-functions-*.pdf`。`scripts/`、`materials/quadratic/README.md`、`README.md` を照合。
- 確認事実：平方根にPDF原稿・ビルドスクリプトがない。二次関数には44問の `materials/quadratic/questions.json` と `scripts/build-quadratic-questions.py` があるが、後者は `assets/quadratic/questions.js` を作るWeb用処理。PDF3冊を再生成する処理ではない。新単元では共通原稿・PDF再生成がある。
- 影響：今後図や説明を直すときにPDFとWebの差分・書式の維持を人手で担うことになる。現在のPDF/Web不一致をこの点だけで断定はしない。
- 改善案：旧PDFの見た目・問題番号を維持して、まず再生成可能な原稿と図の元を管理下に置く。その後に上記の改善を段階反映する。
- 根拠：`scripts/build-quadratic-questions.py` 全35行未満、`materials/quadratic/README.md`、リポジトリ内の関連ファイル一覧。

## 維持したい良い点

- 平方根解説p1の面積4・9・5の正方形は、大きさと辺2・3・√5の関係が整合している。
- 二次関数の図は目視範囲でx・yの単位が同じ。見せやすさのために縦横を歪めていない。
- 平方根の負の平方根・ルートの値の区別、二次関数の「平均」と「一定」の区別、0をまたぐ変域など、よくある誤りへの説明がある。
- 問題集は初回・最後・再挑戦に対応する型を用意し、数学的な意味とテストでの計算練習をつなげている。
- 今回、新単元のスタイルへ一括変更する必要まではない。まず OLD-PDF-01～04 を局所的に改善するのが、既存の良さを保ちつつ学習効果を上げやすい。
