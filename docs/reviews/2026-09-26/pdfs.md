## PDF-01 / P2 / 確定：相似・問14の解答ラベルを辺が横切る

- 場所: `print/similarity-answers.pdf` 7ページ、問14。図中の茶色 `EC = 9` の末尾を茶色の斜辺ECが貫く。青い `AE = 6` も辺に接近している。
- 影響: 求まった値と対応する辺を確認する場面で、線と文字を分離して読む負担が生じる。直前の三平方でユーザーが挙げた問題と同種。
- 原因箇所: `scripts/similarity_answers.py:61–67`。辺の強調を描いた後、固定座標の文字を載せるため、数字の長さや辺の傾きに対応できていない。
- 提案: ラベルを辺の法線方向へ離し、AE/ECそれぞれの中央付近へ置く。必要時のみ短い引き出し線。頂点Eと全体AC=15cmの文字にも余白を残す。
- 証跡: `audit-pdf/similarity-answers/page-07.png`, `audit-pdf/similarity-answer-q14.png`。

## PDF-02 / P2 / 確定：円の交差弦図で数値が弦に重なる

- 場所: `print/circle-guide.pdf` 10ページ、`print/circle-answers.pdf` 10ページ問20（同じ図を使う問題集10ページ問20も確認対象）。
- 表示事実: BXの `4` とDXの `6` が傾いた弦BDの線上に乗る。交点名 `X` も対頂角の印と近く、黒線・数値・角印が一か所へ集まる。解答図の `3` も角印に近い。
- 影響: 対応する辺を見つけて `AX:DX=BX:CX` とつなぐ重要な場面で、数字を先に解読しなければならない。
- 原因箇所: `scripts/circle_figures.py:38–43`。全ての辺のラベルが「中点にx方向+4、y方向−8」の共通オフセット。斜辺の向きに対して垂直に逃がしていない。
- 提案: 数値ラベルは辺ごとに法線方向へ離す。Xは角印から離し、角印の半径と線幅も紙サイズで再調整。同じ弧BCを説明する図なので、BCの弧自体も対象が分かる線種/色で示すとよい。
- 証跡: `audit-pdf/circle-guide/page-10.png`, `audit-pdf/circle-answers/page-10.png`, `audit-pdf/circle-guide-cross.png`。

## PDF-03 / P2 / 改善候補（欠落は確認済み）：円の「足す・引く」で中心の角を探させてしまう

- 場所: `print/circle-guide.pdf` 5–6ページ、`print/circle-answers.pdf` 6ページ問11–12。
- 表示事実: 円周上Pの22°/35°、80°/20°は描かれるが、本文にある中心の44°/70°、160°/40°は図の角印・数字として表示されていない。中心Oの半径線だけを見て、どの範囲を足す/引くかを読者が再構成する必要がある。
- 影響: 一番理解してほしい「円周角も中心角も同じように足す/引く」の対応が、本文のみになる。とくに外側配置は線が密で、160°と40°の範囲を迷いやすい。
- 原因箇所: `scripts/circle_figures.py:95–108`（inside/outsideはPの角印のみ）、`materials/circle/content.json:124–129`、同ファイル問11–12。
- 提案: 円周角の二色と対応する中心角の弧を描き、「44+70」「160−40」がどの角かを図で示す。一つの円へ詰め込むと密になるので、中心部分の小さな拡大図、または2段階の並列図も候補。
- 証跡: `audit-pdf/circle-guide/page-05.png`, `page-06.png`, `audit-pdf/circle-proof-inside.png`。

## PDF-04 / P2 / 改善候補（欠落は確認済み）：平方完成の紙図に辺の長さがない

- 場所: `print/quadratic-equations-guide.pdf` 4ページ。
- 表示事実: 面積 `x²`, `3x`, `3x`, `9` は入っているが、各長方形の辺 `x` と `3`、欠けた角の辺 `3` と `3` が図中にない。右の「角の面積3×3=9」「1辺はx+3」は対象への線や寸法表示を伴わない。
- 影響: 6xを二つの3xに分ける理由、なぜ足りない角が3×3かを、読者が文章と図から補う。Webで丁寧にした理解を、紙単独では同じ粒度で得られない。
- 原因箇所: `scripts/build-quadratic-equations.py:94–97`（PDF）、同20行（静的Web図）、`materials/quadratic-equations/guide.json:160–170`。
- 提案: x×3の2枚、3×3の角、外側のx+3をそれぞれ寸法線で示す。図を大きくするだけでなく、面積と長さを線種・配置で明確に区別する。意味のない全面リデザインは不要。
- 証跡: `audit-pdf/quadratic-equations-guide/page-4.png`。

## PDF-05 / P2 / 改善候補（飛躍は確認済み）：解の公式の紙版で一般形からの途中が省かれる

- 場所: `print/quadratic-equations-guide.pdf` 5ページ。
- 表示事実: 「ax²+bx+c=0を平方完成すると」と記し、直後に `(x+b/(2a))²=(b²−4ac)/(4a²)`、次に解の公式が現れる。aで割る、定数を移す、両辺へ(b/2a)²を足す各段階は載っていない。
- 影響: 直前の数値例が分かっても、b/(2a)やb²−4acがどこから生まれるかを紙単独で追えず、「公式は突然ではない」という説明が納得へ結び付きにくい。
- 原因箇所: `materials/quadratic-equations/guide.json:203–213`。
- 提案: 一般形をいきなり細かい式で埋めず、数値例との2列対応、または短い3段階で「同じ作業」を示す。Web導出への明示参照も用意する。
- 証跡: `audit-pdf/quadratic-equations-guide/page-5.png`。

## PDF-06 / P2 / 改善候補：二次方程式の文章題の解答が式だけで完結する

- 場所: `print/quadratic-equations-answers.pdf` 9ページ問31–32。解説7ページの道路図も合わせて対象。
- 表示事実: 問31は `(8−2x)(12−2x)=60` から計算、問32は高さ15mとなる二時刻1秒/3秒を計算するが、解答ページに図が一枚もない。解説7ページの道路図もxが左の一か所にあるだけで、2xが上下/左右の二つの帯に由来する対応は文字で説明する。
- 影響: 式を立てられなかった子が解答を見ても、図→立式のつまずきを埋めづらい。問32の「上がる途中と下がる途中」も言葉だけで、二次関数とのつながりが視覚化されない。
- 原因箇所: `scripts/build-quadratic-equations.py:104–105,149–155`。解答生成は数式と注記のみ。
- 提案: 問題側は自分で図を作る余地を維持し、解答側に「両端でxを引く」道路図、y=15との交点二つの小グラフを足す。本文全体を図化する必要はない。
- 証跡: `audit-pdf/quadratic-equations-answers/page-09.png`, `audit-pdf/quadratic-equations-guide/page-7.png`。

## PDF-07 / P2 / 確定：紙からWeb体験へ移る入口が紙にない

- 場所: 三平方を除く全15冊。特に `print/similarity-workbook.pdf` 17–18ページと `print/circle-workbook.pdf` 13ページの「Web体験メモ」。
- 検証: pypdfで全15冊161ページを確認し、PDFリンク注釈は全て0。抽出本文には `http` / `github.io` が全冊で0。画像でもWeb体験ページにURL/QRはなく、体験番号と問いだけ。
- 影響: 紙だけを渡したときに、該当するWeb体験へ戻るために親への質問かサイト内探索が必要。紙→Web→紙という教材の中心動線が途切れる。
- 原因箇所: `scripts/build-circle.py:67–70`、`scripts/build-similarity.py` のWeb体験メモ生成と各PDFフッター。平方根/二次関数は生成元不在も別課題。
- 提案: 少なくとも冊子冒頭/末尾に単元の短いURLとQR、Web体験欄には対応する体験名・番号・アンカー付きリンクを示す。電子PDFにはクリックできるリンクも付ける。各ページに大きなQRを並べる必要はない。
- 証跡: `audit-pdf/similarity-workbook/page-17.png`, `page-18.png`, `audit-pdf/circle-workbook/page-13.png`。

## PDF-08 / P3 / 改善候補：相似条件の最初の図が「比較する2図」になっていない

- 場所: `print/similarity-guide.pdf` 5ページ。
- 表示事実: 三辺・二辺と間の角・二角の条件それぞれについて、図は三角形1個ずつ。本文の `3:6 = 4:8 = 5:10` の3組が、図のどの辺同士かは図示されていない。
- 影響: 「3本の辺を見る」は伝わるが、「2つの三角形の対応する3組を比較する」という条件の核心が初見では一段抽象的になる。
- 原因箇所: `materials/similarity/visual-lessons.json:6`、`scripts/similarity_visuals.py` の `three-tests`。
- 提案: 各条件を1個の三角形で記号化する現行を捨てる必要はないが、初回の説明には2図を1組で示し、対応する辺/角がそろう様子を見せる。スペースが足りなければ3条件を3段へ分ける。
- 証跡: `audit-pdf/similarity-guide/page-05.png`。

## PDF-09 / P3 / 要整理：解説ページの「対応する問題」が内容単位とずれる

- `print/similarity-guide.pdf` 17ページ「yだけ2倍は、相似拡大とは違う」には「対応する問題:問29〜32は翌日以降の再挑戦」と表示される。直接この内容を問うのは問28（座標のx/yを2倍にする問題）。`materials/similarity/visual-lessons.json:18` のchapter=`connect`に章共通の案内が紐づくため。
- `print/circle-guide.pdf` 12ページ「円から直角へ。その先は三平方」は対応問題22・23と記載。問22はAP=6/BP=8の三角形面積だが、問23は中心角148°から円周角74°を出す再挑戦であり、このページの直角・面積の主題ではない。`materials/circle/content.json:248–250,657–663`。
- 影響: ページから次の紙問題を選ぶ際、今学んだことの確認先が分かりにくくなる。数学の誤りではなく学習案内の粒度の問題。
- 提案: 「この内容の練習」と「後日の復習」を分け、ページ単位で正確に対応づける。再挑戦問題は解説の元ページへ戻れるよう逆向き参照も作る。
- 証跡: `audit-pdf/similarity-guide/page-17.png`, `audit-pdf/circle-guide/page-12.png`、各問題集。

## 今回、問題と断定しなかったこと

- 全121ページの画像一覧で、ページ外への明らかなはみ出し、章や問題の欠落、広範な文字化けは見つからなかった。
- 円の問題・解答の図中文字が小さく見える件は、実際には生成処理で9.16ptへ下限補正されている。初期の単純縮尺計算による7.13ptという推測は撤回。文字サイズの基準違反とはしていない（pdfplumberでも9.164ptを確認）。問題は局所的な線との重なりと密集。
- 相似の問題図がすべて解答用色分けになっている、という事実はない。対応を考えさせる問5等は問題図と解答図を分けてあり、これは維持したい。
- 余白が多いページを一律に無駄とはしていない。書き込み欄の広さ、1ページ2問などは意図に適う。改善は対象図の意味や読み取りが弱い箇所に限定する。
- 全面のデザイン統一・問題数増加は提案しない。既に分かりやすいページを基準として、上記の局所的な丁寧さと媒体間の接続を優先する。
