# 家族の学習室

中学3年生向けの平方根のWeb教材です。紙の教材と同じ46問を、解説・動く図・練習・振り返りで学べます。外部サービスへのログインやAPIキーは不要です。

## すぐ使う

GitHubの **Code → Download ZIP** で取得し、ZIPを展開して `index.html` をChrome、Edge、Safari、Firefoxなどの新しいブラウザで開いてください。ビルドやインストールは不要です。スクリプト、図、PDFはすべて同梱しており、ダウンロード後はオフラインでも使えます。

数式はブラウザ標準のMathMLで表示します。古いブラウザで数式の表示が崩れる場合はブラウザを更新してください。ローカルファイルでの学習記録の保存可否はブラウザにより異なります。保存できない場合は画面に案内を表示します。

## GitHub Pagesで公開する

この教材は静的サイトなので、Actionsの設定は不要です。

1. このリポジトリの **Settings → Pages** を開きます。
2. **Build and deployment → Source** を **Deploy from a branch** にします。
3. **Branch** を **main**、フォルダを **/ (root)** にして **Save** を押します。
4. Pagesの設定画面に表示される公開URLを開きます。

標準設定での想定URLは `https://hirasunaryou.github.io/for_KT_family/` です。設定が完了するまではアクセスできません。公開されたページはURLを知っている人が閲覧できます。このリポジトリには教材だけを置き、生徒の氏名や学習記録を入れないでください。

## 今日の進め方

休憩・答え合わせを含め80〜100分を目安に、自分のペースで進めます。

1. **はじめの8問**で現在地を確認する。
2. **図と解説で理解**から必要な章を読む。面積と数直線を動かす。
3. **基本の計算 → 式の計算 → 考える4問**に取り組む。途中式は紙に書く。
4. 休憩後に**最後の8問**を解き、同じ型の問題で変化を見る。
5. **発展に挑戦**の4問と**もう一度**の8問は任意。学校で扱った範囲と本人の余力に合わせる。

保護者の方は「簡単でしょ」よりも「どの工夫で解けた？」と聞き、できた手順を具体的に確かめてください。一般的な中3の平方根の内容であり、学校の詳しい範囲表とは未照合です。

## 機能

- 面積1〜36の正方形を、縮尺を保って変形する図。
- √1〜√100の数直線、整数部分と平方数による大小比較。
- 1〜200の整数に対するルートの整理。
- 平方根の意味、計算、有理化、大小、有理数・無理数、応用の5章。
- 印刷用教材と番号が一致する46問。
- はじめと最後の各8問は選択式で自動判定。それ以外は解答・途中式と自己評価。
- ヒント、解答の開閉、確認した解説、最新の自己評価をブラウザに保存。
- 最初の回答と、回答前のヒント・解答閲覧の有無を比較用に保持。再回答や自己評価では上書きしない。
- 学習記録のJSON書き出し・読み込み・リセット。
- モバイル対応、キーボード操作、動きを減らす設定への対応。
- A4の解説PDF 5ページ、問題集7ページ、解答6ページ。

## 保存とプライバシー

学習記録は `localStorage` の `family-square-roots-v1` に保存します。サーバーやGitHubには送信しません。アクセス解析、広告、外部フォント、外部JavaScriptも使いません。GitHub Pagesで閲覧する際には、配信のための通常のアクセスがGitHub側に発生します。

記録は端末・ブラウザ・サイトのアドレスごとです。別の端末、ローカルファイルとPages間では自動同期されません。閲覧データの削除やプライベートブラウジングの終了で消えることがあります。必要なら書き出して保管し、別の環境で読み込んでください。読み込みは現在の記録を置き換えます。

「最初の回答」の点数と「自力でできた」の件数は目的が違います。前者は開始時と終了時の比較、後者は解き直し後の最新の理解度（自己評価を含む）です。選択式の点数だけで理解を断定せず、紙に途中式を書けるかも確認してください。

## 開発と検証

依存ライブラリを必要としないHTML/CSS/JavaScriptです。新しい学習単元は別ディレクトリに追加できます。

ローカルHTTPで確認する場合：

```bash
python3 -m http.server 8000
```

その後、`http://localhost:8000/` を開きます。操作テストは `tests/README.md` を参照してください。
