01 / READ

2乗してから、aをかける。

正方形の1辺が2倍になると、面積は4倍になります。縦も横も2倍になるからです。1辺をx、面積をyとすると、y = x²。このように、xの2乗にyが比例する関係を y = ax² と表します。aは、0以外の決まった数です。

x → x² → a × x² = y

たとえば y = 2x²。x = −3 を入れると、2 × (−3)² = 18。x = 3でも18になります。負のxは、かっこごと2乗しましょう。

xが2倍ならyは4倍。xが3倍ならyは9倍。
倍率も2乗になります。xが半分なら、yは1/4倍です（倍率を比べるとき、元のxは0以外）。

点を通る、は「代入すると成り立つ」。

y = ax² が点 (2, 12) を通るなら、12 = a × 2²。よって a = 3、式は y = 3x² です。xとyをもう一度入れて確かめられます。ただし、原点 (0, 0) だけではaは決まりません。

02 / EXPLORE

aを変えると、何が変わる？

式からつくった点をなめらかに結ぶと、放物線になります。符号が反対で大きさが同じxでは、yも同じ。だからグラフはy軸に対して左右対称で、原点を通ります。

予想してみよう：aを2倍にすると？

a = 1とa = 2を比べよう。x = 2でのyはどう変わるかな。

緑の実線：選んだ式。灰色の破線：比較用の y = x²。選んだ表示範囲の中では目盛りを固定。縦と横の縮尺は異なります。a = 0は比較用で、二次関数には含めません。

aが正なら上向き、負なら下向きに開きます。
|a|（aの絶対値）が大きいほど、開きは狭くなります。同じxで、y軸方向に大きく離れるからです。

aは、直線の傾きではありません。放物線の増え方は場所によって変わります。あとで「変化の割合」の図で確かめましょう。

03 / EXPLORE

端の2点だけで、十分かな？

xの変域は「xが動いてよい範囲」。yの変域は、その間にyがとる範囲です。端だけを見ると、途中で原点を通ることを見落としてしまいます。

予想してみよう：−2 ≤ x ≤ 3 なら？

y = x² で両端のyは4と9。途中に、もっと小さなyはあるかな。

橙の太線：指定したxの区間。青い帯：その区間でyがとる範囲。左端 ≤ 右端を保つよう連動します。

見る順番：aの符号 → 0を含むか → 両端と原点のy。
0を含まない区間では両端を比べます。変域は、小さい数 ≤ y ≤ 大きい数の順に書きましょう。

下向きの放物線で0を含むなら、原点で最大の0になります。「原点なら必ず最小」ではありません。aの符号とセットで判断します。

04 / EXPLORE

「平均してどれだけ増える？」

変化の割合は、yの増加量 ÷ xの増加量。xが1増えるあたり、yが平均してどれだけ増えるかを表します。グラフでは、2点を結ぶ直線の傾きです。

変化の割合 = あとのy − はじめのyあとのx − はじめのx

予想してみよう：同じ1ずつなら同じ？

「1 → 2」と「2 → 3」を比べよう。今度は「−2 → 2」も試してみて。

橙の直線：2点を結ぶ直線。破線の横・縦：x・yの増加量。2つのxの間は0.5以上あけます。

y = x² の変化の割合は、1 → 2では3、2 → 3では5。同じ1ずつでも増え方が違います。−2 → 2では両端のyが等しいので0ですが、途中のyがずっと一定という意味ではありません。

慣れたら使える近道：a(p + q)

y = ax² で、xがpからqへ変わるとき（p ≠ q）、変化の割合は a(p + q) です。

aq2−ap2q−p=a(q−p)(q+p)q−p=a(p+q)

まずは代入して増加量を求める意味を理解し、計算の確認にも使ってみましょう。

05 / CONNECT

座標がわかると、図形も解ける。

放物線 y = x² 上の A(−1, 1)、B(2, 4) を結びます。直線を y = mx + b とおくと、傾きは (4 − 1) ÷ (2 − (−1)) = 1。Aを代入してb = 2なので、直線は y = x + 2 です。

動かしてみよう：底辺と高さはどう変わる？

Aはy軸の左、Bは右に置きます。aや点の位置を変えて、2つの三角形の面積を比べよう。

縦横は同じ縮尺。図中の数字は座標、長さは目盛りで読みます。Aを左、Bを右に置くので、y軸で分けた面積を足せます。a = 0のときは3点が一直線になり、面積は0です。

二次方程式を習ったら：交点を式で求める

交点では、2つの式のyが等しくなります。x² = x + 2 を整理すると (x − 2)(x + 1) = 0。x = 2 または −1 を元の式に入れ、yも求めます。

距離の変化の割合は、平均の速さ。

出発からx秒後までの移動距離y mが y = 2x²（0 ≤ x ≤ 4）で表されるとします。1秒後は2 m、3秒後は18 m。その間の距離16 mを時間2秒で割るので、平均の速さは8 m/sです。

18 ÷ 3 = 6 m/s は「出発から3秒後まで」の平均。
「1秒後から3秒後まで」とは区間が違います。何秒後から何秒後までかを先に確認しましょう。
