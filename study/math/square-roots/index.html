平方根の意味ルートの整理式の計算大きさと数の種類応用の考え方
01

平方根は「2乗の逆」

9の平方根は、2乗すると9になる数。3と−3の2つを、まとめて ±3 と書きます。一方、9 は正のほうの 3だけ を表します。

「9の平方根」は？±3

3² = 9、(−3)² = 9

「√9 の値」は？9=3

ルートの記号は0以上のほう。

正の数の平方根は2つ。0の平方根は0だけ。負の数の平方根は、中学校で扱う数の範囲にはありません。

動かしてみよう

面積から、1辺の長さへ。

面積を変えると、正方形の1辺はどう変わる？

136

同じ縮尺で表示。1マスは面積1。
ここを区別しよう

面積5の正方形の1辺は 5。長さなので正です。√5は「まだ計算していない答え」ではなく、長さを正確に表す数です。

02

平方数を見つけて、外に出す

整数を2乗してできる数が平方数。4、9、16、25、36、49、64、81、100 を目印にします。

72=36×2=62

72 = 36 × 2。36の平方根は6なので、6がルートの外に出ます。中に1以外の平方数の因数が残らないところまで整理します。

かけ算・割り算は、中どうしを計算できる

6×8=48=43

0以上の数a、bでは √a × √b = √(ab)。割り算でも同様に扱えますが、分母は0にできません。

分母の有理化は、上下に同じ数をかける

23=233

分母と分子に√3をかけます。分母は√3 × √3 = 3。上下に同じ数をかけるので、分数の値は変わりません。最後に約分できるか確認しましょう。

03

足せるのは、同じルートの仲間

12+27=23+33=53

2個の√3と3個の√3で、5個の√3。ルートの中を整理してから、係数をまとめます。

√2 + √3 は、そのままでOK。

足し算をルートの中に入れることはできません。たとえば √4 + √9 = 2 + 3 = 5。√13にはなりません。

かっこを2乗するときは、真ん中を忘れずに

(a + b)² = a² + 2ab + b² を使います。

(3+2)2=3+43+4=7+43

和と差の積なら、2乗の差

(a + b)(a − b) = a² − b² を使います。

(5+2)(5-2)=5-4=1

かけ算・割り算を先に計算 → ルートを整理 → 同じ仲間をまとめる、の順で進めましょう。

04

大きさは、平方数ではさむ

16 < 23 < 25 なので、4 < √23 < 5。小数に直さなくても、どの整数の間にあるか判断できます。

有理数と無理数

有理数

整数どうしの分数で表せる数。分母は0以外。

3、0.25 = 1/4、0.333… = 1/3、√9 = 3

無理数

整数どうしの分数では表せない数。

√2、√3、π など

0.333…は3がどこまでも続く循環小数です。「√が付いているから無理数」とは限りません。

負の数では、順番が逆になる

√5 > 2 ですが、−√5 < −2 です。数直線で左にある数ほど小さくなります。

近似値は、整理してから使う

√50 = 5√2。√2を約1.414とすると、√50は約7.070。正確な答えは5√2で、7.070は近似値です。

05

応用は、基本の組み合わせ

ルートが自然数になる条件

「√(18n)が自然数になる最小の自然数n」は？ 自然数は1、2、3、…。ルートの中の18nを平方数にできればよい、と考えます。

18=32×2 → 2をもう1個かける → 18×2=6

3は2個のペア。2だけが1個余るので、もう1個の2をかけます。最小のnは2です。

足す問題か、かける問題かを確認。

√(18 + n)なら、次の平方数25にするので最小のnは7です。

面積から長さを求める

面積12 cm²の正方形では、1辺は次の長さです。

12=23 cm

周の長さは1辺の4倍。

4×23=83 cm

面積はcm²、長さはcm。最後に単位も確認しましょう。
