# 三平方：前の学びが、ここでつながる

中学3年生向け。平方根の「面積から長さ」、円の「直角の理由」、相似の「対応する辺」、二次方程式の「条件を式に」、二次関数の「座標」を実際の問題の中で使います。

## 4つの体験

1. 同じ三角形4枚の並べ替え。形・大きさを保って平行移動する。移動途中の重なりを空き面積の証明として扱わず、両端の配置で比べる。
2. 2辺を固定して角を変える。各辺の正方形と数値を連動させ、直角の条件を確かめる。前の三角形を破線で残し、縮尺は固定。
3. 円の弦／放物線上の点に補助線を引く。横・縦・弦の半分と斜辺を対応させる。点が原点と重なる場合は退化を明示。
4. 箱の底面の三角形、次に高さと作る三角形を取り出す。前段階を残す。見取り図の投影と、同じ縮尺の平面図を分ける。

### 斜辺を見つけ、同じ式から引き算へ（2026-10-01）

解説4の `#side-choice-sequence` は、直角を探す → 斜辺を強調する → x²＋3²＝5²を作る → 数の二乗を計算する → 両辺から9を引く → 整理する → 方程式の解±4 → 長さの条件x＞0から4を選ぶ、の8段階です。直角をはさむ辺x・3と斜辺5という条件を図より前と拡大図に表示します。

三角形を15°刻みで1回転でき、向きが変わっても直角・辺の長さ・斜辺の役割が変わらないことを比較できます。数字は回転させず読みやすい向きに保ち、対応する辺と式の色を合わせます。回転は条件の変更ではないため手順を保ち、戻った場合には未知数の答えを隠します。式変形は前の式と一緒に表示します。

実装は `assets/pythagorean/app.js`。段階への入口、元の解説、面積で定理の理由を追う体験、紙の問6・7への導線を用意し、PDF・印刷・no-JSの解説は保持。`tests/pythagorean-side-choice.cjs` は8手順と全25回転位置を3画面幅で検証し、実座標の辺・直角、図と文字の衝突、式、戻る・途中移動・リセット・キーボード・拡大・印刷を確認します。
