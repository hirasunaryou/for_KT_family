# 三平方：前の学びが、ここでつながる

中学3年生向け。平方根の「面積から長さ」、円の「直角の理由」、相似の「対応する辺」、二次方程式の「条件を式に」、二次関数の「座標」を実際の問題の中で使います。

## 紙とWeb

| 教材 | 内容 |
| --- | --- |
| 解説 | A4・17ページ。冒頭で定理・使える条件・短い例を示し、図の近くの説明と指示線から、式・理由へ進む |
| 問題集 | A4・16ページ。28問を1ページ2問、体験メモ2ページ |
| 解答・解説 | A4・14ページ。求めた値・補助線・式・理由を照合 |
| Web | 共通の解説・28問・4体験・図の拡大・自己評価 |

紙で考える → 解答で確かめる → Webで予想・操作・説明 → 別の問題を紙で解く。

- 1回目：問1〜10と体験1・2。面積・計算・条件。
- 2回目：問11〜20と体験3。図形・円・座標で使う。
- 3回目：問21〜25と体験4。相似と空間へ。
- 問22の相似による証明と、問26の表面の経路は挑戦。無理に一度に進めない。
- 問27・28は翌日以降の再挑戦。

## 4つの体験

1. 同じ三角形4枚の並べ替え。形・大きさを保って平行移動する。移動途中の重なりを空き面積の証明として扱わず、両端の配置で比べる。
2. 2辺を固定して角を変える。各辺の正方形と数値を連動させ、直角の条件を確かめる。前の三角形を破線で残し、縮尺は固定。
3. 円の弦／放物線上の点に補助線を引く。横・縦・弦の半分と斜辺を対応させる。点が原点と重なる場合は退化を明示。
4. 箱の底面の三角形、次に高さと作る三角形を取り出す。前段階を残す。見取り図の投影と、同じ縮尺の平面図を分ける。

## 原稿・生成

- `content.json`：導入＋16解説・28問の条件・ヒント・答え・理由・図のデータ。
- `labs.html`：体験の予想、操作、振り返り。
- `scripts/pythagorean_figures.py`：共通ベクトル図。座標と長さが一致する構成。
- `scripts/build-pythagorean.py`：HTMLと3冊のPDFを生成。
- `assets/pythagorean/model.js`：長さ、並べ替え、弦、座標、空間の純粋計算。
- `assets/pythagorean/app.js`・`style.css`：操作・表示・保存。
- `previews/`：版付きの確認用PDF（解説はv4、問題集・解答はv3が最新版）。正式なリンクは `print/pythagorean-*.pdf`。

```sh
python3 -m pip install reportlab fonttools
python3 scripts/build-pythagorean.py --font /path/to/static-japanese-font.ttf
npm run test:pythagorean
npm test
```

日本語の静的TrueTypeフォントが必要です。使用文字はPDFへ埋め込みます。初版はNoto Sans JPの400を使用。閲覧時の外部依存・通信はありません。

本文・図・問題番号の変更は共通原稿に反映し、生成物だけを直接変更しないでください。
