対象は y = ax²（a ≠ 0）。高校の一般形は対象外です。

- [解答と解説（8ページ）](../../print/quadratic-functions-answers.pdf)

A4、白黒印刷向け。問題集は片面印刷がおすすめです。

今日の中心は問題集1〜6ページ（34問）。7ページの発展4問と8ページの再挑戦6問は任意です。休憩・答え合わせを含め80〜100分が目安ですが、必要な型を選んで取り組めます。

問題番号1〜6と29〜34は同じ型の確認問題。39〜44はさらに数字を変えた再挑戦です。変化の割合、原点を含む変域、直線と図形、平均の速さを扱います。二次方程式で交点を求める発展は、既習の場合に取り組みます。

questions.json は、今後のWeb版に対応させるための44問のデータです。下向き・正誤などの回答は表示時に日本語化し、倍率・単位も問題に合わせて添えます。図・表はPDFを参照してください。Web版は [二次関数の教材](../../study/math/quadratic-functions/index.html) に実装しています。Web表示用のMathMLは assets/quadratic/questions.js に同梱しています。
