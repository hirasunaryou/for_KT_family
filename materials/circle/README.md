# 円：角の見方から、相似の道具へ

相似に続く中学3年生向け教材。紙で考え、Webで予想して動かし、別の問いへ戻ります。

## 構成

- 解説12ページ：弧の見方、円周角の定理、3つの位置での証明、逆、活用、次の学び。
- 問題集13ページ：24問を1ページ2問、最後に体験メモ。
- 解答・解説12ページ：24問の図・途中式・理由と間違いやすい点。
- Web3体験：円周上の点を動かす／補助線と証明を段階表示／直径と90°の条件を崩して比べる。
- 紙とWebの番号・条件・解答を共通原稿で管理。解説の図は拡大表示できます。

## 問題の進み方

| 問題 | 焦点 |
| --- | --- |
| 1〜4 | 頂点を含まない弧、中心角と円周角 |
| 5〜8 | 同じ側・反対側、180°を超える弧 |
| 9〜12 | 二等辺三角形と外角から証明する |
| 13〜18 | 直径、定理の逆、円に内接する四角形 |
| 19〜22 | 相似、接線、直角三角形の面積へ使う |
| 23〜24 | 翌日以降の再挑戦 |

半径を引く意味を図の近くで示し、中心が角の辺上・内側・外側にある場合をつなぎます。交わる弦では既習の相似を使い、最後は三平方の定理への入口にします。実験で気づいたことと証明は区別します。

## 生成元

- `content.json`：12解説・24問題、ヒント・解答・理由。
- `labs.html`：3つのWeb体験。

- `assets/circle/app.js`・`style.css`：操作、保存、図の拡大、表示。

```sh
python3 -m pip install reportlab fonttools
python3 scripts/build-circle.py --font /path/to/static-japanese-font.ttf
npm run test:circle

```

日本語の静的TrueTypeフォントを指定します。PDFに使用文字を埋め込み、閲覧時に外部フォントは不要です。生成物を直接編集せず、原稿・図・生成処理を修正してください。

## 円周角の対応と理由を動かして確かめる（2026-09-27）

- 体験1は「Pから見る → Oから見る → 両方を比べる」の3つの入口。青い弧ABはPを含まない方に固定し、反対側へ移ったときは中心でも240°の優角を表示する。位置・側・見方を変えたら確認結果を隠す。前のPの輪郭と固定縮尺を保つ。
- 体験2は `assets/circle/proof-steps.js`。基本形7手順、中心が内側8手順、外側8手順。半径→等しい底角→外角→足す／引く→同じ弧の関係へ進む。数値は一例として扱い、最後はxまたはα・βで一般の関係を説明する。
- 青と茶の角はPとOで対応し、式も同じ色にする。外側では青い大きい角の中に茶色の角を重ね、差として元の角を取り出す。配置ごとに現在位置を保持し、前後・リセット・拡大を使える。
- 解説4〜6から各配置へ直接移動でき、体験から問7〜12へ戻れる。PDF・問題番号は変更しない。
- `tests/circle-stories.cjs`：23手順×3画面幅の角の実測値、文字と線の衝突、図の固定位置、境界操作、配置別の保持、リセット・拡大・リンクを確認。体験1では3つの見方・両側・複数位置で優角と表示を検証する。既存の保存・PDF・印刷用の静的教材・JavaScript無効時の構成は維持する。

## 半円と円1周から角の関係を考える（2026-09-28）

`assets/circle/angle-links.js` が解説7・9に段階表示を追加します。直径は4手順で、条件→Pを含まない半円→中心角180°→円周角90°。四角形は6手順で、Aの弧→Cの弧→円1周→それぞれ半分→合計180°へ進みます。PまたはDを円周上で動かせ、図の位置・縮尺を固定して角・弧・式が連動します。Dの変化では、AとCの角の値は変わっても合計が180°に保たれます。

元の完成図・解説は印刷とJavaScript無効時に保持し、Webでもまとめて読めます。戻る・リセット・拡大、問13/14/18/24と条件を崩す体験への導線を用意しました。PDF・問題番号は変更しません。`tests/circle-angle-links.cjs` は10手順×3位置×3画面幅と全スライダー位置で、角の独立計算・文字と線・固定図・操作・リンク・印刷/no-JSを検証します。

通常の改善は、ルート `AGENTS.md` の方針に従い、全体テストと公開確認まで進めます。

## 円から相似・接線の既習事項へ（2026-09-28）

`assets/circle/prior-learning.js` が解説10に8手順、解説11に5手順を追加します。交わる弦では、対頂角→同じ弧BCの円周角→相似→対応→2倍→CX=8 cmと進みます。元の図を残し、同じ縮尺・実際の辺の長さで2つの三角形を同じ向きに並べます。「等しい角」「対応」「長さ」の入口で見直す位置を選べます。

接線では、接点への半径→直角→既知の角→残りの角の順に表示します。Bを動かすと2つの角が連動し、合計90°を保ちます。問19〜21、相似、三平方への導線があります。紙の条件・問題番号・PDFは維持し、静止図は印刷・JavaScript無効時にも表示します。

`tests/circle-prior-learning.cjs` は13手順×3画面幅、接線の全操作位置、角と辺の独立計算、取り出した三角形の縮尺、文字と線の重なり、前後・リセット・途中移動・拡大・問題リンク・印刷・JavaScript無効時を確認します。

## 直角から、底辺・高さと面積へ（2026-09-29）

`assets/circle/area-bridge.js` が解説12を本筋4手順＋任意の寄り道2手順にします。問22の条件を常時表示し、直径→Pの直角→底辺と高さ→知っている三角形の公式で面積24 cm²、までで問題を解き終えます。回転には「見やすい向きにして底辺と高さを確かめる」という目的を添え、もう見えている人はそのまま次へ進めます。

本筋の最後に「公式は使える。あえて別の見方で考えてみる？」と問いかける入口を用意します。利用者が選んだときだけ同じ三角形をもう1枚合わせ、長方形の半分として「÷2」を捉え直します。寄り道からは、本筋の計算結果へ図の向きを保ったまま戻れます。

回転は利用者のスライダー操作、または「底辺APを水平にする」で行います。AP＝6 cm・BP＝8 cm、直角、縮尺、面積を保ち、寄り道では同じ三角形を合わせた長方形も一緒に回ります。自動進行はありません。3つの見直し入口、前後・リセット・拡大、問22と三平方の解説8へのリンクを設け、元の静止解説は印刷・JavaScript無効時に残します。PDF・問題番号・条件は変更しません。

`tests/circle-area.cjs` は本筋4手順＋寄り道2手順・全21回転位置・3画面幅で、描画座標から辺の長さ・垂直・面積・追加した三角形の合同を確認します。本筋だけで解けること、明示操作だけで寄り道に入ること、復帰時の向きとフォーカス、文字同士／線との衝突、図の範囲、答えの先出し、操作・拡大・リンク・印刷・JavaScript無効時も検証します。

## 寄り道：補助線は、どうやって思いつく？（2026-09-30）

`assets/circle/proof-steps.js` が体験2の末尾に任意で開く寄り道を追加します。基本形（P・O・Aが一直線、Oが中心）に固定し、「線を足す前」「中心OとBを結ぶ」「AとBを結ぶ」を同じ位置・縮尺で比較します。OBでは等しい半径・二等辺三角形・等しい底角、ABでは直径PAに対する直角が見えます。

「円では中心へ結ぶ」を手順の暗記にせず、使いたい性質から線を選ぶ感覚を育てる狙いです。ABも面積や三平方で役立つので、不正解の選択肢にはしません。元の証明の配置・手順は変えず、寄り道を閉じてそのまま続きを読めます。PDFと本筋の説明は保持します。

`tests/circle-auxiliary.cjs` は3候補×3画面幅で等しい半径・底角・直角を独立に検証し、文字と線の衝突、図の範囲、証明の状態保持、キーボード・閉じる・拡大・印刷・no-JSを確認します。
