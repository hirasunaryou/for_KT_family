# 円：角の見方から、相似の道具へ

相似に続く中学3年生向け教材。紙で考え、Webで予想して動かし、別の問いへ戻ります。

## 構成

- 解説12ページ：弧の見方、円周角の定理、3つの位置での証明、逆、活用、次の学び。
- 問題集13ページ：24問を1ページ2問、最後に体験メモ。
- 解答・解説12ページ：24問の図・途中式・理由と間違いやすい点。
- Web3体験：円周上の点を動かす／補助線と証明を段階表示／直径と90°の条件を崩して比べる。
- 紙とWebの番号・条件・解答を共通原稿で管理。解説の図は拡大表示できます。

## 問題の進み方

| 問題 | 焦点 |
| --- | --- |
| 1〜4 | 頂点を含まない弧、中心角と円周角 |
| 5〜8 | 同じ側・反対側、180°を超える弧 |
| 9〜12 | 二等辺三角形と外角から証明する |
| 13〜18 | 直径、定理の逆、円に内接する四角形 |
| 19〜22 | 相似、接線、直角三角形の面積へ使う |
| 23〜24 | 翌日以降の再挑戦 |

半径を引く意味を図の近くで示し、中心が角の辺上・内側・外側にある場合をつなぎます。交わる弦では既習の相似を使い、最後は三平方の定理への入口にします。実験で気づいたことと証明は区別します。

## 生成元

- `content.json`：12解説・24問題、ヒント・解答・理由。
- `labs.html`：3つのWeb体験。
- `scripts/circle_figures.py`：紙とWeb共通の正確なベクトル図。
- `scripts/build-circle.py`：3冊のPDFと静的HTMLを生成。
- `assets/circle/model.js`：角度と弧の純粋計算。
- `assets/circle/app.js`・`style.css`：操作、保存、図の拡大、表示。

```sh
python3 -m pip install reportlab fonttools
python3 scripts/build-circle.py --font /path/to/static-japanese-font.ttf
npm run test:circle
npm test
```

日本語の静的TrueTypeフォントを指定します。PDFに使用文字を埋め込み、閲覧時に外部フォントは不要です。生成物を直接編集せず、原稿・図・生成処理を修正してください。

## 検証

- PDF全37ページを画像化して確認。番号・本文・途中式と原稿の照合。
- 問題図で解答の値を先に見せない。問22の6:8の長さも図と一致。
- 独立した内積計算と弧の計算で円周角の数値を照合。退化・端点・反対側を確認。
- Web3体験、結果の再非表示、前段階表示、保存拒否、他単元との保存分離。
- 390/768/1440px、等縮尺、図の境界、PDFリンク、JavaScript無効、オフラインを検証。
- 初版作成時に既存教材を含む `npm test` が完了。
